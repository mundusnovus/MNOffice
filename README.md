# Asteria Office

Documents, spreadsheets, presentations and PDFs at **office.asteria.technology**, saved in Asteria Cloud, with
desktop apps for Windows, macOS and Linux. Built on Euro-Office.

Work in progress. The plan and every decision so far are in [AGENTS.md](AGENTS.md).
